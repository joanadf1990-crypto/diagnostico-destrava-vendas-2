# Diagnóstico Destrava Vendas

Página única (HTML) do diagnóstico comercial com 31 perguntas em 5 blocos.
Ao final, o botão **ENVIAR DIAGNÓSTICO** abre o WhatsApp do gestor com todas as respostas organizadas, endereçadas ao número da Destrava Vendas; o gestor só toca em enviar.

Publicação: Vercel (site estático, sem build). Arquivo principal: `index.html`.
